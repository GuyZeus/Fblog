使用 Docker + 1Panel 部署个人博客实战指南

📅 2026年7月15日🏷️ Docker, 1Panel⏱️ 约 10 分钟阅读

我的博客 blog.guyzeus.top 基于 Halo Pro + MySQL + Docker 部署，面板使用 1Panel 管理。本文分享完整部署流程，帮你也拥有自己的博客。

一、为什么选 1Panel

1Panel 是开源的 Linux 服务器运维管理面板，对比宝塔它更轻量、无广告、纯 Docker 化部署，非常适合个人开发者。

  • 一键安装 Docker、Nginx、MySQL 等环境
  • 可视化容器、镜像、网络管理
  • 内置应用商店，Halo、WordPress 等一键部署
  • 免费的 SSL 证书申请与自动续期

二、安装 1Panel

curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh
bash quick_start.sh

安装完成后访问 http://服务器IP:目标端口，登录后第一件事是修改默认密码和安全入口。

三、部署 Halo

在「应用商店」搜索 Halo，选择版本后填写数据库参数。建议单独创建一个 MySQL 容器供 Halo 使用，不要和面板共用。

关键配置：外部访问地址务必填你的域名 https://blog.guyzeus.top，否则后台资源会加载 404。

四、Nginx 反向代理 + SSL

1Panel 的「网站」功能可自动创建反向代理并申请 Let's Encrypt 证书：

server {
  listen 443 ssl;
  server_name blog.guyzeus.top;
  location / {
    proxy_pass http://127.0.0.1:8090;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
  }
}

五、数据备份

务必在 1Panel 中设置定时备份，将 Halo 的 ~/.halo2 目录和 MySQL 数据卷备份到对象存储或本地其他磁盘。

六、总结

从零到博客上线大约 30 分钟。Docker 化部署最大的好处是环境隔离、一键迁移——换服务器只需备份数据卷，重新拉起容器即可。
