现代 CSS 布局完全指南：Flexbox 与 Grid 实战

📅 2026年6月15日🏷️ CSS, 前端⏱️ 约 11 分钟阅读

Flexbox 和 Grid 是现代 Web 布局的两大核心工具。本文通过实际案例帮你彻底搞定它们。

一、Flexbox：一维布局

Flexbox 适合沿「一条轴线」排列元素，常用于导航栏、卡片内布局。

.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

二、Grid：二维布局

Grid 适合同时控制行和列的「网格」布局，如卡片墙、仪表盘。

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 1rem;
}

三、本站布局解析

本博客采用「固定侧边栏 + 流式主内容」布局：侧边栏 position: fixed，主区域 margin-left 留出空间，配合 max-width 限制阅读宽度。

四、响应式技巧

  • 用 clamp() 做流式字号
  • 移动端把侧边栏改为抽屉式（transform + overlay）
  • minmax() + auto-fill 实现自适应列数

五、总结

Flex 管一维，Grid 管二维。两者配合能覆盖绝大多数布局需求，几乎不需要 float。
