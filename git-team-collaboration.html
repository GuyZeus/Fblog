Git 团队协作工作流：分支策略与冲突解决

📅 2026年5月12日🏷️ Git, 协作⏱️ 约 8 分钟阅读

Git 是现代开发不可或缺的版本控制工具。本文介绍团队协作中最常用的分支策略与冲突解决方法。

一、常见分支策略

  • Git Flow：master + develop + feature + release + hotfix，适合有版本发布的软件
  • GitHub Flow：只有 main + feature 分支，简单，适合持续部署
  • GitLab Flow：在 GitHub Flow 基础上加入环境分支（如 pre-prod）

二、日常流程

git checkout -b feature/login
git add .
git commit -m "feat: 登录功能"
git push -u origin feature/login

三、冲突解决

合并冲突时，Git 会在文件中标记冲突区域：

<<<<<<< HEAD
你的代码
=======
对方代码
>>>>>>> branch-name

手动编辑保留正确内容后，git add + git commit 即可。

四、总结

频繁 pull、小步提交、写好 commit message，能规避 80% 的协作烦恼。
