Spring Boot RESTful API 设计最佳实践

📅 2026年5月30日🏷️ Spring Boot, RESTful⏱️ 约 10 分钟阅读

好的 API 设计能让前后端协作事半功倍。本文总结一套 Spring Boot RESTful API 设计规范。

一、URL 设计规范

  • 用名词复数表示资源：/api/students 而非 /api/getStudent
  • 用 HTTP 方法表达动作：GET 查、POST 增、PUT 改、DELETE 删
  • 层级关系用嵌套：/api/students/{id}/courses

二、统一返回格式

public class Result<T> {
  private int code;
  private String msg;
  private T data;
}

三、参数校验

用 @Valid + JSR-303 注解在 Controller 入口校验，避免脏数据进入业务层。

public Result<Void> add(@RequestBody @Valid StudentDTO dto) { }

四、统一异常处理

用 @RestControllerAdvice 全局捕获异常，返回统一错误结构，前端无需关心异常类型。

五、总结

一致性优于聪明。团队约定好规范并严格遵守，比任何花哨设计都重要。
