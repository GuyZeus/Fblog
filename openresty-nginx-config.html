OpenResty 入门：Nginx 配置与 Lua 脚本实战

📅 2026年7月8日🏷️ OpenResty, Nginx⏱️ 约 8 分钟阅读

OpenResty 是一个基于 Nginx 与 LuaJIT 的高性能 Web 平台，它让你可以用 Lua 脚本在 Nginx 的各个处理阶段插入自定义逻辑，实现限流、鉴权、灰度发布等能力。

一、OpenResty 是什么

通俗地说，OpenResty = Nginx + LuaJIT + 一堆精心封装的 Lua 库。它把 Nginx 从一个「静态文件服务器 / 反向代理」升级成了「可编程的应用服务器」。

二、安装

# CentOS / Rocky
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo https://openresty.org/package/centos/openresty.repo
sudo yum install -y openresty

三、第一个 Lua 脚本

在 Nginx 配置中嵌入 Lua，返回当前时间：

location /hello {
    content_by_lua_block {
        ngx.say("Hello from OpenResty! Time: ", ngx.localtime())
    }
}

四、实战：简单限流

利用 lua-resty-limit-traffic 库实现按 IP 限流：

lua_shared_dict my_limit_store 100m;

location /api/ {
    access_by_lua_block {
        local limit = require "resty.limit.req"
        local lim, err = limit.new("my_limit_store", 100, 50)
        local delay, err = lim:incoming(ngx.var.binary_remote_addr, true)
        if not delay then
            ngx.exit(503)
        end
    }
    proxy_pass http://backend;
}

五、应用场景

  • API 网关：统一鉴权、限流、日志
  • 灰度发布：按 Cookie 或 Header 分流
  • 动态路由：从 Redis 读取路由规则，无需 reload
  • 边缘计算：在 CDN 边缘节点做个性化逻辑

六、总结

OpenResty 的学习曲线不陡，但威力巨大。对于需要高性能、低延迟动态逻辑的场景，它是比「Nginx + 后端服务」更优雅的方案。
