Java 集合框架深度解析：ArrayList vs LinkedList

📅 2026年6月28日🏷️ Java, 集合框架⏱️ 约 9 分钟阅读

ArrayList 和 LinkedList 是 Java 中最常用的两种 List 实现。本文从底层数据结构出发，帮你理解它们的本质差异与选型依据。

一、底层结构

ArrayList 基于动态数组实现，内存连续；LinkedList 基于双向链表，节点分散，每个节点保存前后指针。

二、时间复杂度对比

操作ArrayListLinkedList
随机访问 get(i)O(1)O(n)
尾部插入 add()O(1)*O(1)
中间插入O(n)O(n)**
删除O(n)O(n)**

* 均摊；** 找到节点后插入/删除本身是 O(1)，但查找节点需 O(n)。

三、内存占用

ArrayList 有容量冗余（默认 1.5 倍扩容），但每个元素只存引用；LinkedList 每个节点额外多存两个指针，内存开销更大。

四、选型建议

  • 读多写少、需要随机访问 → ArrayList
  • 频繁在头部/中间增删 → 考虑 LinkedList，但多数情况 ArrayDeque 更优
  • 不确定就默认用 ArrayList，它综合表现最好

五、总结

面试常考，实际开发 90% 场景用 ArrayList 即可。理解原理比死记结论更重要。
